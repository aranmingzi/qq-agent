# 模型 API / 人设 UI 控制修复（2026-10-20）

用户反馈：「模型API、人设等方面的UI控制好像有些bug」。

查下来的第一现场不是界面：`data/config.json` 里

```json
"api": { "provider": "custom_munnnea318yh", "apiKey": "sk-????????107d" }
```

而 `providers[]` 里同一家的真密钥是好的。也就是说**机器人一直在拿一串问号当 API Key 调模型**，
界面却显示「密钥已配置」，报错信息也只会是 401，很难联想到是界面保存时写坏的。

## 一、密钥被写成问号（根因 + 三层防御）

链路：`maskSecretValue()` 用 U+2022 圆点做掩码 → 掩码出现在某次往返里被按 ASCII 编码写成 `?` →
`isMaskedSecret()` 只认 `••` / `****`，认不出 `????` → 掩码被当成真密钥落盘。

修法：

1. **掩码只用 ASCII**（`src/app.js`）：`sk-****107d`，编码转换不再变形。
2. **`isMaskedSecret()` 增加 `/\?{4,}/`**：问号残骸同样按掩码 strip 掉。
3. **`healMaskedSecrets()`**（`src/config.js`）：`loadConfig()` 与 `updateConfig()` 都会跑，
   发现配置里出现掩码就按 `providers[]`（同 id / 同 baseURL）把真密钥找回来，找不到就清空
   （宁可显示「未配置」，也不拿问号去打接口）。同时处理 `vision.qwen.apiKey`、
   `audio.apiKey`、`snowluma.accessToken/httpAccessToken`、`webSearch.anysearchKeys`。

现在即使某条路径又把掩码写进去，落盘前也会被还原。

## 二、切换服务商后密钥没跟着走

`POST /api/config` 以前只做 deepMerge：`api.provider` 换了，`api.apiKey` 还是上一家的 →
在模型目录里选一个新服务商的模型，测试/聊天必然 401（而目录里明明有 key）。

现在：`api.provider` 变化时自动套用该服务商的 `apiKey` / `baseURL`（目录里有就用，没有就显式清空）；
用户手填的新密钥也会回写 `providers[]`，避免"下次切一次又被改回去"。

## 三、新版控制台（`console/`，Electron 默认入口）

| 问题 | 表现 | 修法 |
| --- | --- | --- |
| 「获取列表」不落库 | 提示"已获取 N 个模型；保存后写入配置"，但保存根本不带 providers，刷新就没了 | 调 `/api/providers/models` 真写入（新 Base URL 走 `POST /api/providers`）；本地同步用并集（后端是追加语义） |
| 「获取列表」强迫重贴密钥 | 后端 `resolveRequestKey` 本来就支持同 baseURL 复用已保存密钥 | 前端只在「确实没有可用密钥」时才拦 |
| 人设下拉点了没反应 | value 是独立 state，onChange 只开弹窗不改它 → Radix 受控 Select 立刻弹回 | 改成按 `roleText` 反查派生 |
| 自定义人设删不掉 | 删除按钮只在下拉命中时出现，而下拉永远显示占位符 | 新增「自定义人设（N）」列表，每项带删除；当前人设标「当前」 |
| 添加人设丢字段 | 新建人设没有「管理员附加规则」输入 | 补回 `customRules` |
| 预设写脏值 | 保存时 `preset` 写后端不认识的 `'custom'` | 改为 `null` |

## 四、旧版 UI（`ui/`，回退通道）

- `state.personaTemplates` 漏存 `customRules` → 选自定义人设会把「管理员附加规则」静默清空。
- 删除自定义人设后 `loadSettings()` 把已删文本从配置灌回输入框（看起来"删了又回来"）
  → 现在先从内置默认人设回填并立即落盘。
- `syncVisionSwitch()` 遇到 no-vision 模型会 `checked=false` + disabled，保存一次就把
  `api.vision` 永久关掉（换回支持图片的模型也不恢复）→ 现在只禁用、不改值。
- 补内联 favicon，消除 `/favicon.ico` 404。

## 六、注意事项

- 掩码样式从 `sk-••••••••107d` 变成 `sk-****107d`（纯 ASCII）。
- 后端改动需要重启进程才生效（本次已重启一次，OneBot 已自动重连）。
- 新版控制台需要 `npm run build:electron` 重新构建到 `ui-console/` 才会生效。
