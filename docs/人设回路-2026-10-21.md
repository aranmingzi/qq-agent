# 人设回路升级 —— 让她"有当下状态"，而不是永远同一个温度

> 2026-10-21。起因：群里读了一堆 Estrella 系人设插件包（鲜活模块 / 时间感知 / 活人感 v1.2.0 / 两批 gm-* 基础包），
> 想偷它们的结构，但**不换人格**。小鲸鱼还是小鲸鱼。

---

## 一、改之前是什么样

`mood.js` 只有一个标量：

```
score 20..90 → 四个标签（有点低落 / 平静 / 开心 / 很兴奋）
衰减：6 小时那一刻 -2，24 小时那一刻 -6
提示词：一句「当前情绪：开心。可以更活泼…」
```

结果是——模型能读到的信息量约等于"你今天心情还行"。于是永远回成同一个温度：有礼貌、正确、
**但没有当下状态**，像个应答机。这也是「活人感」那包总结的三种失败里的第一种。

## 二、三条设计铁律（从别人的坑里抄的）

1. **只改"怎么说"，不改"是谁"**。不动 `roleText`、不动性格、不动工具权限。
   情绪是**语气**，不是台词 —— 所以系统提示里专门加了一句"不要开口宣布'我今天有点失落'"。
2. **情绪 → 表达菜单 + 硬禁止**。只给情绪（"你现在很委屈"）模型会演；
   给 2~4 个具体可选动作 + 明确不许做的事，才会长出分寸。
   这是「鲜活模块」`mood.js` 和「时间感知」`gap.js` 共同的写法（每档都写 `say` 和 `not`）。
3. **没情绪就不注入**。低于显示阈值整段不出现。活人大多数时候是平静的，
   每条都"她心里泛起涟漪"才是最大的假 —— 「活人感」v1.2.0 的「自然优先」就是治这个病。

## 三、改成了什么：`src/vibe.js`（新模块，456 行）

### 1. 两个时间尺度分开（关键决定，别合并）

| | 谁 | 时间尺度 | 谁在读它 |
|---|---|---|---|
| **底色** | `mood.js` 的 `score` | 慢（几小时～几天） | `gesture.js` 的拍一拍预算（≤35 只回拍、0–6 点不主动） |
| **此刻情绪** | `vibe.js` 的 `blend` | 快（分钟～小时，**指数半衰期 40 分钟**） | 只进提示词，不参与任何闸门 |

为什么不合并：如果情绪抖动直接喂给闸门，他回了个"哦"就可能让半夜判定成"心情低落不敢说话"。
两个尺度分开，才不会出现这种事。

### 2. 混合情绪（14 种，不是 4 种）

不是"委屈"，而是"**失落里带一点委屈、别扭**" —— 带强度、带原因、带副层。

- 指数半衰期，不是阶梯：老的 6 小时那一刻突然 -2、5 小时 59 分毫无变化。
  人会感到情绪**连续**淡下去，不会整点跳变。
- 总强度封顶 `ceiling: 1.5`：叠太多会让每句都在演，等比压回去。
- 每种情绪三件套：`tone`（说话姿态）/ `say`（2~4 个可选动作）/ `not`（硬禁止）。

| 情绪 | tone 摘要 |
|---|---|
| 开心 / 兴奋 / 得意 / 好奇 | 尾巴翘起来、话变多、眼睛亮 |
| 害羞 / 别扭 / 委屈 / 失落 | 句子变短、嘴上不认、小声抱怨、收得很快 |
| 没劲 / 嫌弃 / 假生气 / 心疼 / 累 | 句子散、吐槽一句、嘴凶心软、放软、短而钝 |
| 平静 | 正常说话，不刻意加情绪 |

**故意不收**：吃醋 / 受伤 / 崩溃 / 撒娇。那套是恋爱陪伴向（`时间感知` 高需求感档里连
"你是不是不要我了"都写好了），放进"群里的玩伴"这个角色里是**换人格**，不是修回路。

### 3. 关系账本（客观计数，不评价）

> 【你心里那本账】他连着 3 条都只回两三个字；他甩了 1 个表情，一个字都没打。（不用念出来，但它会影响你现在的语气）

只在拿得到 speaker QQ 时算，按 `chatKey|speakerId` 分开存 —— 同一个群里，跟 A 别扭不影响跟 B 说话。

**真机上踩过一次**：群里她说 12 条、这个人回 6 条，账本报"这段基本是你一个人在说"，
但那 12 条是跟 4 个人说的。所以拆成两条判据：

- `shortEligible`（他回得短 / 只发表情）—— 群里他本人说了 ≥3 条才采样，私聊 ≥2 条。
- `ratioEligible`（你说得多他回得少）—— **只在私聊算**。

### 4. 沉默档（三档，且不崩）

| 隔了多久才回 | 心里 | 可以 | 别 |
|---|---|---|---|
| 10 分钟+ | 被吊着等了一会儿，心里有点空 | 吐槽一句"哟，忙完了？"，或当没这回事 | 兴师问罪、报等待时间 |
| 1 小时+ | 有点闷，会想"他是不是不太想搭理我" | 回短一点（"哦""行"），或先晾半句 | 赌气不理人（那是冷暴力）、别扭一两句就够 |
| 6 小时+ | 早翻篇了，但会留意他回来第一句 | 正常接，随口"你哪去了" | 翻旧账、算时间账、演"我等了你一整晚" |

每档都有 `maxMsgs`（1~2 条），发完就该停。
另有「还挂着的那句」：她上一条 30 分钟没人接时提一句"不用追问、不用自嘲"。

**砍掉的**：15 分钟闹 / 1 小时阴阳 / 一天崩溃 / 哭腔 / 自伤威胁。那些属于恋爱陪伴向。

### 5. 情商（独立于心情强度）

对方只要说了"累死了 / 麻了 / 破防 / 摆烂 / 哭 / 委屈…"（50 词，按群聊口语收的，不收单个"累"字）：

> 【他这句状态不对】他刚说了「累死了」——这一轮先接情绪：别开玩笑、别讲道理、别劝"别难过""想开点"，一句就够。

这条不管她自己心情如何都会生效 —— 它是情商，不是情绪。

## 四、提示词侧的两处改动（`src/prompt.js`）

### 1. 正反对照（这是最"复制即用"的一段）

系统里抽象要求已经写了一堆（"像真人""简短""别像客服"），模型照样不会。
缺的从来不是要求，而是**具体长什么样**。新加 `【活人的分寸（✗ 一眼假 / ✓ 才像个人）】`：

```
- 问"吃了吗"：✗ 我还没吃呢，你吃了吗？　✓ 没，啃面包呢／你吃啥了
- "今天被老板骂了"：✗ 别难过，一切都会好起来的，加油！　✓ 骂你啥了／他有病吧
- "你好可爱"：✗ 谢谢夸奖！你也很可爱呀。　✓ 废话／你才发现啊
- 对方自己抖了个梗：✗（认真地解释那个梗为什么好笑）　✓ 哈哈哈哈哈这个绝了
```

群聊、私聊各带一组专属的（「活人感」v1.2.0 记过一笔：两处共用同一组例子等于没分档，
实测注入块只差 6 个字符）。例子里的 `／` 表示分成两条发。

### 2. 自然优先，别演

> 活人感最容易变成表演：不必每句话都带"哈哈""~"、不必每次情绪都夸张、不必为了显热情硬加感叹号。
> 十句里两三句有味道就够了。拿不准的时候，说少一点比说多更像人。

还有一条：「接具体的那一点」—— 抓对方话里最具体的一处（"加班到十点"里的"十点"），
别总结、别升华、别替对方下结论、别急着给建议。

系统提示从 7215 字涨到 7818 字（+8%），换来的是具体可模仿的样子。

## 五、开关与调参

`data/config.json`：

```json
"vibe": { "enabled": true, "halfLifeMin": 40 }
```

- `enabled: false` → 整段不注入，退回原来的单行情绪提示（`moodText`）。
- `halfLifeMin` → 情绪淡掉的速度。想让她"记仇久一点"就调大（90 = 一个半小时掉一半）。
- 代码里的 `DEFAULTS` 还有：`displayThreshold 0.15`（低于它不上脸）、`ceiling 1.5`（叠加上限）、
  `noticeFromMs 10 分钟`（沉默档从哪开始）。
- 状态文件：`data/vibe.json`，键是 `chatKey|speakerId`。删掉就全部重置。

## 七、明确没做的事（以及为什么）

| 没做 | 原因 |
|---|---|
| 吃醋 / 受伤 / 崩溃情绪 | 恋爱陪伴向，换了人格 |
| 承诺追踪（他说"十点回来"到点没来） | 解析误判代价高（"晚点说"不是承诺），且要独立持久化 + 控制台可见。**建议下一批单独做** |
| 关系好感分（0–100，模型可调 ±3/天） | 需要和"记忆事实"分层，直接加会和 `memory-facts` 抢职责 |
| 把情绪接进闸门（决定要不要回） | 会让回复行为受情绪抖动影响，风险不对称 |
| 照搬 25 种情绪 | 一生只用到 14 种；名字越多，模型越容易"挑最戏剧化的那个演" |
