# 链接直接翻唱：B站 / 音乐平台能不能吃

2026-10-21。之前 `sing_lyrics` / `sing_convert` 的 `url` 参数只认「音频直链」，
群友贴一条 B站 或 网易云 链接进来，翻唱必然失败——而且报的错极有误导性：
`ffmpeg 解码失败：Output file #0 does not contain any stream`，看着像「没装解码器」，
实际是**把一张 50KB 的 HTML 页面当成 mp3 存进了曲库**。

现在按站点分流，B站链接和音乐平台链接都能直接拿去翻唱。

## 一、支持矩阵（都是实测，不是查文档）

| 链接 | 结果 | 耗时 | 走哪条路 |
|---|---|---|---|
| `bilibili.com/video/BV…`、`b23.tv/…` | ✅ 能翻唱 | 4 s | yt-dlp 取音轨 |
| YouTube / 抖音 / 快手 / 西瓜 / 微博 / 小红书 | ✅ 能翻唱 | 视站点 | yt-dlp 取音轨 |
| `music.163.com/song?id=…`、`163cn.tv/…` | ✅ 能翻唱 | 10~16 s | 提歌名 → B站找原曲 |
| `y.qq.com/…/songDetail/…` | ✅ 能翻唱 | 9.5 s | 提歌名 → B站找原曲 |
| 酷狗 / 酷我 / 咪咕 歌曲页 | ✅ 能翻唱（同网易云路径） | 同上 | 提歌名 → B站找原曲 |
| 音频直链 `.mp3/.flac/…` | ✅ 能翻唱 | 1 s | 直接下 |
| 不认识的站点 | ❌ 明确报错 | — | 不硬试 |

实测链路（网易云《晴天》）：页面解析出「晴天 / 周杰伦」→ 曲库没有 → 点歌台缓存没有
→ B站搜「晴天 周杰伦」→ 5 条里选 `【4K Hi-Res】晴天-周杰伦`（270 s，匹配 1.041）
→ 下 6.0MB m4a（4:29.74，48kHz 立体声 AAC 183kbps）。

## 二、音乐平台为什么不能直取

三条路都死了，而且死法各不相同：

1. **网易云外链播放接口** `music.163.com/song/media/outer/url?id=x.mp3`
   → `302 Location: https://music.163.com/404`。这个老接口已经彻底关了。
2. **yt-dlp 原生 extractor**：网易云报
   `No media links found; possibly due to geo restriction`（IP 在国内也这么说，是匿名 API 被拒）；
   QQ音乐报 `This video is only available for registered users`，要 cookies。
3. **浏览器 cookies**：`--cookies-from-browser chrome` 报
   `Failed to decrypt with DPAPI`。Chrome 新版的 app-bound 加密，Python 侧解不开。

所以音乐平台走「**提歌名 → B站找原曲搬运**」。这不是凑合：
B站上的无损搬运音质往往比平台的 128k 匿名流还好，且不用登录。

页面标题解析实测：

```
网易云  → 晴天（Sunny Day） - 周杰伦 - 单曲 - 网易云音乐    → 晴天 / 周杰伦
QQ音乐  → 晴天 - 周杰伦 - QQ音乐-千万正版音乐海量无损曲库…  → 晴天 / 周杰伦
```

## 三、四个必须记住的坑

**1. B站搜索不带 cookie 一律 412**
`yt-dlp "bilisearch:起风了"` 直接 `HTTP Error 412: Precondition Failed`。
先 `GET https://www.bilibili.com/` 拿 `buvid3` + `b_nut`，再带着搜，就正常了。

**2. `--playlist-end` 对 `bilisearch:` 无效，条数靠 `bilisearch5:`**
用 `bilisearch:xxx --playlist-end 6` 只回 1 条。要写 `bilisearch6:xxx`（实测回 5 条）。

**3. B站搜索有频率风控**
连着搜两三次就 412。`searchBilibili()` 里做了两道缓冲：全局最小间隔 2.5 s + 412 时换新 cookie
并退避 3/6 s 重试。实测「网易云链接 + QQ音乐链接」连着测会触发，隔几秒就好。

**4. 不要让 yt-dlp 做 `-x` 转码**
`-x --audio-format mp3` 会调 ffmpeg，而本机 ffmpeg 不在 PATH，直接
`Postprocessing: ffprobe and ffmpeg not found`。所以只下原始音轨（m4a/webm），
要转交给项目统一的那条 `media-tools.resolveFfmpeg()`。
B站音轨实测就是 `30280` = 192k AAC，够翻唱。

## 四、选源打分（这条决定「唱的是不是原曲」）

在 B站搜到 5 条之后按分数挑，规则写在 `link-audio.js::pickBestTrack()`：

- 直播/回放/翻唱/伴奏/纯音乐/教学/reaction/合集/鬼畜 → **直接排除**
- 时长 < 45 s 或 > 600 s → 排除（预览、循环两小时的都别要）
- 歌名命中 +0.5；命中率 < 60% 的**直接丢掉**
- 歌手命中 +0.25
- 「无损/Hi-Res/音质」+0.12，「官方/MV/完整版」+0.06，现场 −0.06，remix/DJ −0.2
- 播放量取对数，最多 +0.15

> 为什么卡「歌名命中率 < 60% 就丢」：只靠歌手对得上，「七里香 周杰伦」能拿 0.43 分，
> 足以把真正的《晴天》挤下去。唱错歌比唱不出来更糟——所以宁可返回 null 不唱。

## 五、接在哪里

| 位置 | 行为 |
|---|---|
| `fetchAudioBufferFromUrl()`（`tools.js`） | 直链/视频站/音乐平台统一入口，`sing_convert` 和 `sing_lyrics` 都走它 |
| `sing_lyrics` 的 `url` | 传链接即可；另外会从 `title`/`lyrics` 里**捞链接**（模型常把链接塞进歌名） |
| `coverSong({src})` | `src` 直接给链接也行，自动下载后再翻唱 |
| `resolveLinkAudio()`（`link-audio.js`） | 单条链接 → 本地音频文件，返回 `via` 说明走了哪条路 |

音乐平台还会**先查本地**：曲库 `songs/raw` 有这首就直接用（0 网络），
其次点歌台 `data/playlist/audio` 有转好的 mp3 也用。都没有才上网。

## 六、探针命令（出问题先跑这三条）

```bash
cd /d/QQagent

# 1. yt-dlp 在不在
./diffsinger-env/Scripts/python.exe -m yt_dlp --version

# 2. B站能不能下音轨（不转码）
./diffsinger-env/Scripts/python.exe -m yt_dlp --no-warnings --no-playlist \
  -f "ba[ext=m4a]/ba/b" --print after_move:filepath -o "work/_probe.%(ext)s" \
  "https://www.bilibili.com/video/BV1GJ411x7h7"

# 3. 音乐平台链路（含搜索 + 选源）
node --input-type=module -e "
import { resolveLinkAudio } from './src/link-audio.js';
console.log(await resolveLinkAudio('https://music.163.com/song?id=186016',
  { dir: 'work/_probe', stem: 'x', log: console.log }));
"
```

## 七、边界

- **B站 1080P 高码率要会员**，但音轨不要——我们只取音轨，不受影响。
- **合集/多 P**：`--no-playlist` 只取当前 P。
- **直播回放**：能下，但选源时已被排除（不完整、有串场）。
- **付费数字专辑**：B站通常没有搬运，会如实报「没找到能用的原曲」。
- **版权**：这些只适合处理自己合法拿到的内容。解出来/下下来不等于有权传播——
  群里自娱自乐没问题，别拿去二次分发。

## 八、做过但放弃的方案

**musicdl**（PyPI 2.14.2，聚合网易云/QQ/酷狗）：依赖声明不全，装它要补
`click / json-repair / rich / prompt_toolkit / m3u8 / cryptography / av / ytmusicapi …`
十几个包，而它 2023 年的接口大概率也已失效。装了半截就止损了，**别回头再试**。

**B站搜索自己调 wbi API**：要自己实现 md5 混淆表签名，代码量比复用 yt-dlp 大得多，
且同样要过 412 风控。没做。
