# 小鱼语音 · 训练方式总结（2026-10-28 整理）

> 目标：用「昔涟」的语音素材，在 GPT-SoVITS v2 上做一次微调，得到比零样本更像、更稳的小鱼声音。
> 最终产出：`xilian_s1_e7.ckpt`（GPT）+ `xilian_clean.pth`（SoVITS），即 `01-语音包`。

## 二、素材从哪来、怎么处理

1. **来源**：B 站抓 22 个「昔涟」相关视频的 DASH 音轨（m4a，约 44MB），保存到 `voice/xilian/corpus/`。
2. **转 wav**：ffmpeg 转成 **32kHz 单声道**，放 `corpus_wav/`（GPT-SoVITS v2 要 32k）。
3. **切分**：`slice.py` 按能量 VAD 切成短片段，得到 **192 条 / 16.5 分钟**，放 `clips/`，清单 `clips_manifest.jsonl`。
4. **清洗**：手动/BGM 检测剔掉带背景音乐、噪声、B 站口播的片段，最终留 **97 条干净片段**（`xilian_clean` 用这套；`improve2` 用 158 条标注版）。
5. **标注**：faster-whisper medium 转写 + 人工校正，写进 `train.list`，格式固定：

```
/绝对路径/xilian_00001.wav|xilian|zh|这一句的文本
```

（`|名字|语种|文本`，三竖线分隔；`exp_name` 与这里都叫 `xilian`。）

> 参考音 `ref_1..4.wav` 也从素材里切，已 loudnorm 到统一响度；`prompts.json` 存每段参考音的转写文本。

## 三、预处理（GPT-SoVITS 五套中间文件）

训练前必须先生成这几套，`improve.ps1` / `improve2.ps1` 就是干这个的：

| 步骤 | 脚本 | 产出 |
| --- | --- | --- |
| 1 | `prepare_datasets/1-get-text.py` | `2-name2text.txt`（文本 → 音素/语义特征索引） |
| 2 | `prepare_datasets/2-get-hubert-wav32k.py` | `3-bert/`、`4-cnhubert/`、`5-wav32k/` |
| 3 | `prepare_datasets/3-get-semantic.py` | `6-name2semantic.tsv` |

关键环境变量（脚本里已设）：

```
inp_text   = xilian/train.list
exp_name   = xilian
opt_dir    = gsv/logs/xilian
version    = v2
is_half    = True
bert_pretrained_dir   = .../chinese-roberta-wwm-ext-large
cnhubert_base_dir     = .../chinese-hubert-base
pretrained_s2G        = .../gsv-v2final-pretrained/s2G2333k.pth
```

注意：改标注后要**先删旧中间文件**（2-name2text / 6-name2semantic / 3-bert / 4-cnhubert / 5-wav32k），否则会沿用旧特征。

## 四、训练

### s1（GPT / 韵律）

```powershell
# s1-run.ps1
& $vpy s1_train.py --config_file "$gsv\configs\s1_xilian.yaml"
```

- 用 `s1_xilian.yaml`（基于 v2 预训练 `s1bert25hz-5kh-longer-epoch=12-step=369668.ckpt` 继续训练）。
- 最终保留 **epoch 7**：`gsv/logs/xilian/logs_s1_v2/ckpt/epoch=7-step=72.ckpt`，拷贝成 `GPT_weights_v2/xilian_s1_e7.ckpt`。

### s2（SoVITS / 音色）

```powershell
# improve.ps1（97 条干净版，最终用的这套）
& $vpy s2_train.py -c "$gsv\configs\s2_xilian.json"
```

- `s2_xilian.json`：`name = xilian`，`epochs = 12`，`save_every_epoch = 4`，从 `s2G2333k.pth` 初始化。
- 训练完 G/D 权重在 `gsv/logs/xilian/logs_s2_v2/G_233333333333.pth`、`D_...pth`。

### 训练踩过的坑（真踩过）

1. **s1 保存时报 `FileNotFoundError: xilian-e8.ckpt`**：保存目录不存在，e8 没落盘；e7 是好的，直接用 e7。
2. **s2 结束时报 `'HParams' object has no attribute 'name'`**：只是保存路径取属性失败，训练本身已完成，权重已经在 `logs_s2_v2/`，别慌。
3. **`parallel_infer: true` 必报分布式错**：推理时一律 `false`。
4. **`pyopenjtalk` 编不了**（本机没 MSVC）：去掉，只影响日语。
5. **`opencc` 编不了**：换 `opencc-python-reimplemented`。
6. **`jieba_fast` 编不了**：装 `jieba`，在 site-packages 里造 `jieba_fast` 兼容层（转发 jieba + posseg）。
7. **transformers 必须 ≤ 4.51.3**：更新的版本拒绝 torch<2.6 加载 `.bin` 权重。

## 五、导出成可加载权重

```powershell
# convert_g.py：把训练产出的 G_*.pth 转成 TTS 能直接加载的 SoVITS 权重
& $vpy convert_g.py <G_233333333333.pth> SoVITS_weights_v2/xilian_clean.pth
```

输出形如 `saved 673 tensors -> ...xilian_clean.pth`。

s1 的 `epoch=7-step=72.ckpt` 直接拷成 `GPT_weights_v2/xilian_s1_e7.ckpt` 即可。

## 六、切到最终版并推理

```powershell
# 1) 切换权重 + 重启 9880
.\apply.ps1 -S1 "...\GPT_weights_v2\xilian_s1_e7.ckpt" -S2 "...\SoVITS_weights_v2\xilian_clean.pth" -Ref ref_1

# 2) 合成
node voice.mjs "要念的话" ref_1
```

合成参数（调过，别乱改）：

```
temperature 0.6 | top_k 12 | top_p 0.85 | speed_factor 0.95
sample_steps 32 | repetition_penalty 1.3 | parallel_infer false
```

后处理：

```
highpass=f=80,afftdn=nr=8:nf=-40,deesser=i=0.3,equalizer=f=3000:t=q:w=1.2:g=2,loudnorm=I=-16:TP=-1.5:LRA=11
```

输出 mp3 256k，不二次重采样。

## 七、环境

- Python 3.10（uv 装），torch 2.5.1+cu121，CUDA 可用（RTX 2070 8G）。
- `voice/gsv-venv/` 是 GPT-SoVITS 专用环境；`voice/venv/` 是切分/标注用的。
- `voice/bin/ffmpeg.exe` 静态版 7.1。
- 预训练权重在 `gsv/GPT_SoVITS/pretrained_models/`（s1 369668 / s2G2333k / hubert / roberta / sv）。

## 八、复现最小步骤

1. 装好 GPT-SoVITS v2 + `gsv-venv`（torch cuda）。
2. 准备 `xilian/clips`（32kHz 单声道）+ `train.list` 标注。
3. 跑 `improve.ps1`（97 干净版）或 `improve2.ps1`（158 全量版）。
4. `convert_g.py` 导出 G 权重；s1 拷 epoch 7。
5. `apply.ps1` 切过去，`voice.mjs` 试一句。
