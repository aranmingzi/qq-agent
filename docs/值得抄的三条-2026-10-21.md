来源：Estrella 社区包 100 个（第一批 42 + 第二批 7 + 第四批 50）+ 三个高敏模块。

## 一、群梗：候选 ≠ 已知（`src/memes.js`）

### 为什么

之前 `memes.js` 是**纯只读**的：`data/memes.json` 手工维护 15 条，模型只有 `search_meme`，
查到就用、查不到就 web_search。听着很安全，问题在另一头 —— **它没有地方记新梗**。
群里冒出个新词，模型要么装懂（编一个意思），要么每轮都去搜（浪费），要么彻底无视。
三种都不像人。

社区包 `gm-meme-archive` 的处理是两级：**谁都能提 → 只有 operators 能看 → 确认/忽略**，
并且写死一句「待确认内容不得当已证实事实」。这条正中要害：
模型说"这是个梗"不等于"这是个梗"。

### 怎么做的

```
data/memes-pending.json   ← 候选池。模型只能写这里。**永远不进提示词、永远不被 search 命中**
data/memes.json           ← 正式库。只有人确认过的才进来。search 只读这里
```

关键纪律写进代码，不靠自觉：

| 谁是 | 能做什么 | 在哪 |
|---|---|---|
| 模型 | `propose_meme` 提候选（key + 释义必需） | `tools.js` |
| 人 | 确认 / 拒绝 | 控制台「设置 → 群梗库」、`/api/memes/*` |
| `search_meme` | **只读 `memes.json`** | `memes.js::searchMemes()` |

`proposeMeme()` 的四种拒绝都带原因（模型读得到，会自己收敛）：

- `duplicate` — 已在正式库（含别名撞车）→「已经在梗库里了，正常用就行」
- `rejected-before` — 被人拒过 →「之前被判定过不是梗，别再提」
- `full` — 池子满 50 条 →「先别加了」（**不淘汰旧的**：淘汰会让它反复重提，变成拉锯）
- `bad` — 没写释义 →「至少要说清它是什么意思」

同一个梗被提多次只累计 `hits`（三个人都在说，是"更像梗"的证据），不新增条目。

提案返回里有一条硬约束字段 `reminder`：

> 这条现在只是候选：**不许**在回复里表现得你已经懂了它，也别拿它玩梗。

### 控制台入口

`/settings/memes`（侧边栏：设置 → 消息 → 群梗库）。每条候选显示 key / 听过几次 / 释义 / 用法 /
别名 / 来源群，右边两个按钮「不是梗 / 收录」。页头有一句横幅专门解释"候选期间 AI 查不到、也用不了"——
这条文案是这一页存在的理由，别删。

### API

```
GET  /api/memes/pending        → { ok, pending: [...], rejectedCount }
POST /api/memes/confirm        { key, patch? }   patch 可以顺手改释义（人话比模型写的准）
POST /api/memes/reject         { key, note? }
```

失败时同时返回 `reason` 和 `error`（控制台的 `request()` 只认 `error`，
否则失败原因会被吞成"请求失败（HTTP 400）"）。

### 自检

`test/test-memes.mjs`（17 项）。最重要的一条：

```js
ok('新梗提成候选后，搜索依然查不到（关键）', ...)
```

候选能进 search 就等于"记成候选"变成了自我授权的后门，这条断言守住它。

## 二、被连戳会毛（`src/gesture.js::pokeStreak`）

### 为什么

`shouldPokeBack()` 只保证"不刷屏"：同一个人 60 秒只回一次。可如果对方隔一分钟戳一下、
戳五下，它每次都乖乖回拍 —— 那就不是人，是个弹簧。真人被连戳到第四下会毛。

### 判据

```js
pokeStreak({ count, lastAt, now, cfg })
→ { count, angry, level: 'calm'|'annoyed'|'angry', note }
```

- 同一会话同一个人，两次戳间隔 **> `pokeStreakResetMs`（默认 5 分钟）** 重新从 1 数
- 到 **`pokeAngryAt`（默认 4）** 起 `angry: true`，之后继续戳一直算"还毛着"，隔 5 分钟才自然消退
- 第 3 下给一句「他今天戳你有点勤，这是第 3 下」（`annoyed`），但不拦回拍
- `Math.max(2, ...)` 兜底：没人能把它配成"两下就炸"

### 两条接线，方向相反

**入站（`app.js::ingestPoke`）** —— 炸毛了就**不回拍**：

```
第 1~3 下 → 正常回拍，存档追加「（已经拍回去了）」
第 4 下起 → 不回拍，存档追加「（他连着戳了你 4 下）（这次没拍回去）」
```

**故意不自动发台词。** 自动台词连着三次一样就成了复读机；存档里的括号说明交给模型，
它自己决定哼一声、损一句还是晾着。

**出站（`tools.js::send_poke`）** —— 炸毛了也不许它自己补拍：

`pokeHistory()` 现在多返回 `inboundPokes`（最近 5 分钟内这个人拍你的条数，窗口与
`pokeStreakResetMs` 同源）。超过阈值直接拒绝，并告诉它：

> 他刚连着戳了你 N 下，你正毛着呢 —— 回拍反而像没脾气。想反应就直接说一句，
> 别动手。

两处判据看起来冗余，其实是必需的：入站管"手反射"，出站管"模型临时起意"。
少一处，模型都有办法绕过去。

### 调参

`config.gesture.pokeStreakResetMs` / `config.gesture.pokeAngryAt`，
默认 5 分钟 / 4 下。想让它更没耐心就调 3，想让它更钝就调 6。

### 自检

`test/test-gesture.mjs` 新增 6 项（连戳共 41 项）。

## 三、`configSchema` 透传（`plugin-manifest.js` / `plugin-api.js`）

### 那个坑长什么样

清单里写：

```json
"configSchema": {
  "volume": { "type": "number", "label": "音量", "default": 60 }
}
```

但加载器**只留了键名**（`schemaKeys: ['volume']`），`configSchema` 本体丢了；
`settingsOf()` 又只从 `manifest.settings` 取默认值，不看 schema 的 `default`。
于是插件的 `api.config()` 返回 `{}`，读到 `undefined`，静默走错分支。

最阴的是**测试是绿的** —— 因为测试自己传了 `settings`；生产没人传，就坏在那儿。
Estrella 作者在注释里专门记过这一条。

### 改了三处

1. `normalizeConfigSchema()` 保留本体：`type / label / help / default / options / min / max`
   - 未知 `type` 按 `string`（一个坏字段不该让插件装不上）
   - 没有 `label` 就用键名（控制台不用再猜）
   - **用 `hasOwnProperty` 判断有没有 `default`**：`default: undefined` 与"没写 default"
     必须能区分，否则"想让默认值是空"会被当成"没设默认值"又被覆盖回去
2. `settingsOf()` 三层合并：**schema default < `manifest.settings` < 用户填的**
3. `plugin-host.js` 三处快照透传 `configSchema`（record / activateOne / skip 分支）

### 自检

`test/test-plugin-schema.mjs`（10 项）。带星号那条就是当年的 bug：

```js
ok('★ 只写 configSchema、不写 settings 时，config() 也能拿到默认值（生产场景）', ...)
```

## 没做的那一条：关系好感的硬额度

评估里排第 3（★★★☆☆，别急），这次仍然不做，原因不是懒：

它要改的是 `vibe.js` 的核心状态（`blend` 单值叠多情绪），还要接提示词和衰减曲线。
「单次 ±3 / 单日总 10 / 60 秒冷却 / 主人固定值不可改」这套额度本身很简单，
难的是**额度花完之后怎么表现**——是变冷淡？还是只是不再涨？这属于人格决策，不是代码决策。

现在的替代方案：`vibe.js` 的 `ledgerFacts()` 已经只报客观计数（"他连着 3 条都只回两三个字"），
不下判断。等哪天真觉得"她对每个人都一样好"是个问题，再动它。

## 顺带确认的两条边界写法（只记不用）

- `markdown-reader`：**协议未证明该消息属于当前会话就拒绝读取**。跟我们"拿不到 QQ 绝不猜"
  同源，我们的 `matchMember()` 已经是这个立场（重名一律返回 null）。
- `ai-spotter`：把 `caution: 短样本不可可靠识别 AI` 直接写进工具返回值。
  **把不确定写进返回值，而不是让模型自己编一个确定答案。**
  我们的 `search_meme` 命中失败时的 note 就是这个写法，这次顺手把 `propose_meme` 也补上了。
