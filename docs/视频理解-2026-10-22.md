# 看视频（视频链接 → 内容总结）

2026-10-22 · 目标：群友甩一个视频链接，agent 自己先"看"一遍，说得出它大概讲了什么。
效仿 DSH 养鱼生态里那个"接上 B站，读字幕、弹幕和关键帧再给主人总结视频"的插件。

代码：`src/video-intel.js`（判据 + 抓取 + 总结）、`src/app.js::autoWatchVideo`（入站自动看）、
`src/tools.js::watch_video`（模型主动看）、`src/prompt.js` 9.2 条（提示词对齐）。
自检：`test/test-video-intel.mjs`（40 条纯逻辑 + `VIDEO_LIVE=1` 联网）。

---

## 一、为什么要有这一层

模型手里只有一个 URL。它的选项只有两个：**编造内容**（最糟）或**老实说"我看不了视频"**。
真正能拿到的东西都得靠代码去抓：标题、简介、章节、字幕、弹幕、热评、画面。
所以这一层做的是「**把视频变成能读的材料**」，然后才轮到模型归纳。

三条硬规矩（写死在代码和提示词里）：

1. **只认材料，不编内容。** 材料只有标题时，总结必须说"只看得到标题，具体内容我不确定"。
2. **缺什么要留痕。** 每一步失败都进 `intel.missing`，最后写进给模型的材料文本
   （`【没拿到的材料】… —— 这些部分不要猜`）。静默降级 = 让"总结得挺像"其实是模型脑补。
3. **每一步都能单独失败。** 字幕拿不到不影响弹幕，弹幕拿不到不影响标题；
   全都没有才算失败（返回 `ok:false` + 人话原因）。

## 二、能拿到什么（都是实测）

### B站（官方 API，最快最全）

| 接口 | 给什么 |
| --- | --- |
| `x/web-interface/view?bvid=` | 标题 / UP主 / 时长 / 简介 / 置顶(dynamic) / 封面 / aid / cid / 分P / 播放点赞 |
| `x/player/v2?bvid=&cid=` | **章节（view_points）** / 字幕轨 / `need_login_subtitle` |
| `x/tag/archive/tags?bvid=` | 标签（十来个，最能说明"这是什么类型的视频"） |
| `x/v1/dm/list.so?oid=<cid>` | 弹幕 XML（返回是 deflate，Node fetch 自动解） |
| `x/v2/reply?type=1&oid=<aid>&sort=2` | 热评（按热度） |

- ⚠️ **必须带 `buvid3`/`b_nut` cookie**：不带一律 412（和 `link-audio` 踩的是同一个坑，
  所以这里直接复用它的 `biliCookie()`，不另写一份）。
- ⚠️ **AI 字幕要登录**：`player/v2` 里 `subtitle.subtitles` 匿名基本是空的，
  且会给 `need_login_subtitle`。这两种情况在 `missing` 里写的是不同的话
  （"AI字幕（要登录，匿名拿不到）" vs "字幕"）——否则以后查日志会一直以为接口坏了。
- 弹幕聚合（`aggregateDanmaku`）给两份：**高频榜**（大家都在刷什么）+ **时间线**（按 6 个时间桶取代表弹幕，
  能看出"从头到尾在讲什么"）。短视频（<2 分钟）不切桶，桶里没东西反而更看不懂。
  单条 >50 字直接丢（B站上限就是 50，超了必是拼接刷屏）。

### 其余站点（yt-dlp `-J`，不下载）

YouTube / 抖音 / 快手 / 西瓜 / 微博 / A站…：标题、简介、UP主、时长、章节（chapters）、标签，
以及**字幕轨**（`subtitles` 人工优先于 `automatic_captions` 自动；语言序 zh-Hans → zh-CN → zh → zh-TW → en，
格式挑 json3 → vtt）。YouTube 的自动字幕通常能拿到，这是最值钱的材料。

### 兜底

抓页面 `og:title` / `og:description`。只够说"这是个什么标题的视频"，足够不留空白。

### 关键帧（真"看"画面）

`extractFrames()`：yt-dlp 下最差画质 → ffmpeg 均匀抽 N 帧（躲开片头片尾各 3%）→ Qwen-VL 描述。
实测 120 秒的视频端到端 7.9 秒。

默认**关**（`video.keyframes=false`）：要先下整个视频，群里随手一个链接就可能几百 MB。
三道闸：ffmpeg 存在 / 视觉模型配了 key / 时长 ≤ `maxFrameDurationSec`（默认 900s）。
工具可以临时要一次（`keyframes: true`）。

## 三、两种触发方式

### ① 入站自动看（`app.js::autoWatchVideo`）

消息里有视频链接 → 解析预算通过 → 抓材料 → 让模型总结 → 直接发回群里。
和"拍一拍当场回拍""点歌台当场播"是一个道理：**这种事不该赌模型这一轮会不会想起调工具**。

分寸（照 `gesture` 那套）：

- 深夜 `quietFromHour~quietToHour`（默认 0–6 点）不开口；
- 同一会话冷却 `perChatCooldownMs`（默认 60s）、一小时最多 `maxPerHour`（默认 4）；
- 同一个链接 30 分钟内不重复（群里转好几遍很常见）；
- 话里带"翻唱/唱一首/点歌/歌单"→ 不抢戏，交给唱歌链路；
- **失败一律静默**（只进日志）。解析不出来还回一句"我看不了"，比沉默更吵。

发完总结后：如果这条消息**除链接外基本没别的话**（"看下这个""讲啥的"也算），
就把这条标记已读 + 记一条 DIRECTIVE skip，不再叫模型回一句（已经答过了，再答就是重复）。
消息里还有别的内容时留给模型自由接话。

### ② 模型主动看（`watch_video` 工具）

追问细节用：值不值得看、某段讲了啥、有没有讲 XX。有缓存（默认 12h），同一个链接几乎秒回。
返回里带 `materials` / `missing`，提示词明确要求"缺的部分不许脑补"。

## 四、两个踩过的坑

1. **max_tokens 被思考吃光。** 推理模型的思考过程也占 `max_tokens`。
   6000 字材料 + 只给 400 → 思考写完就没额度 → `content` 为空，
   表现像"模型拒答"，其实是我们自己把输出掐了。现在给 `summaryMaxChars*1.5+400`（≥800），
   并且空结果会自动砍掉 2/3 材料再问一次。
2. **`worst` 会挑到纯音轨。** B站音视频是分开的流，只写 `worst` 拿到的是音频，
   ffmpeg 抽帧直接失败。抽帧必须用 `worstvideo[height<=480]/worstvideo/...`。

（次要）整体预算：抓取最多占六成 `timeoutMs`，剩下留给模型总结 ——
材料抓到了却没额度总结，等于白抓。

## 五、配置（`config.video`）

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `enabled` | true | 总闸；关了不自动看，工具也不挂载 |
| `autoReply` | true | 解析完自动发回群里；false = 只留着让模型自己决定说不说 |
| `keyframes` | false | 是否抽帧真看画面（会下整个视频） |
| `maxFrameDurationSec` | 900 | 超过就不抽帧 |
| `frameCount` | 4 | 抽几帧（1~6） |
| `maxChars` | 6000 | 喂给模型的材料上限 |
| `cacheHours` | 12 | 同链接多久内复用总结；0=不缓存 |
| `danmakuTop` / `commentTop` | 12 / 8 | 高频弹幕 / 热评条数 |
| `summaryMaxChars` | 400 | 总结目标长度（给模型的字数要求，不硬截） |
| `quietFromHour` / `quietToHour` | 0 / 6 | 静默时段 |
| `perChatCooldownMs` / `maxPerHour` | 60000 / 4 | 同一会话的冷却与小时上限 |
| `timeoutMs` | 30000 | 单次"看视频"总超时 |

缓存落在 `data/video-cache.json`（最多 200 条，满了按时间淘汰一半），
抽帧临时文件落在 `data/video/frames/`（用完即删）。

## 六、验证

```bash
node test/test-video-intel.mjs                       # 40 条纯逻辑
VIDEO_LIVE=1 node test/test-video-intel.mjs          # + 真抓一个 B站视频
VIDEO_LIVE=1 VIDEO_SUMMARY=1 node test/test-video-intel.mjs   # + 模型总结（要配好模型）
VIDEO_URL=https://www.bilibili.com/video/... VIDEO_LIVE=1 node test/test-video-intel.mjs
```

联网用例默认不跑：B站有 412 风控，把网络抖动当成 bug 会养出假红。

实测样本（`BV1pGnn67EbB`，44 分钟）：材料 = 标题/简介/弹幕/标签/热评，缺 AI 字幕；
总结如实写了"具体每段讲什么我没拿到字幕，不敢乱猜"，并用了弹幕时间点描述氛围 —— 正是想要的效果。
