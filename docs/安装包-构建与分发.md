# 安装包：构建与分发

这份文档讲的是「怎么把 QQ Agent 打成能直接装到别人电脑上的安装包」，以及「发给别人之后对方要做什么」。
给最终用户的说明在安装目录里的 `README.html`；这是给维护者看的。

---

## 一、一句话结论

```bash
npm run build:installer
```

跑完在 `dist-installer/` 得到三个可以直接发人的文件：

| 文件 | 用途 |
| --- | --- |
| `QQagent-Setup-1.0.0.exe` | 安装程序。对方双击 → 一路下一步 → 桌面图标启动 |
| `README.html` | 使用说明。跟着 Setup 一起发，也装进安装目录 |
| `SHA256SUMS.txt` | 校验和。对方怕下坏 / 怕是病毒时用来核对 |

外加 `QQagent-1.0.0-win.zip`（免安装绿色版，同一份载荷）和 `app/`（中间载荷，可以删）。

## 二、整条流水线做了什么

`tools/make-installer.mjs` 分七个阶段：

1. **载荷（复用便携包管线）**——调 `tools/make-portable.mjs`，把工程里该带的东西拷进 `dist-installer/app/`，同时：
   - 清空 `data/`：只留脱敏后的 `config.json`、`config.example.json` 和空骨架目录；
   - 剔除所有 API Key、token、secret 字段，清空白名单群号、`masterQQ`、`snowluma.accountQQ`；
   - NapCat 的 `config/napcat_<QQ>.json`、`onebot11_<QQ>.json`、`guild<N>.db*` 一律不带；
   - 重刷 `snowluma/config/webui.json` 的 token；
   - 跑一遍泄露自检，命中任何 QQ 号 / 群号 / 密钥就以退出码 2 结束。
2. **安装版二次裁剪**——便携包里对安装版没用的东西删掉：`test/`、`tools/portable/`、
   `启动 QQagent.bat`、`首次使用必读.md`、`node_modules/@electron*`、`@types`、
   `electron/dist/debug.log`，`locales/` 55 个语言包只留 `en-US.pak` + `zh-CN.pak`，
   清空 `snowluma/logs`、`snowluma/cache`、`data/electron`，删掉编辑器遗留的 `*.bak-*`。
   - **身份脱敏**（`scrubIdentifiers`）：把开发者的真实 QQ 号、群号、账号昵称、本机绝对路径
     （`C:\\QQagent`）统一替换成示例值（`10000001`…`10000007`、`小鲸鱼`、`C:\\QQAgent`），
     出厂 `masterQQ` 直接清空（用户自己填）。只改构建产物，不动 `src/`。
     紧接着 `auditIdentifiers()` 复扫一遍，命中任何真实标识就打印 `x 身份残留` 并让自检失败。
3. **品牌化**——把 `node_modules/electron/dist/electron.exe` **就地改名**成 `QQ Agent.exe`，
   再用 `rcedit` 写入图标（`tools/installer/qqagent.ico`）与版本资源（产品名、公司、版权、版本号）。
   > 代码里没有任何地方依赖 `electron.exe` 这个文件名（只有便携包的 `.bat` 依赖，而安装版不带它），
   > 所以改名不影响启动；`electron/main.js` 里自启动用的是 `process.execPath`，改名后依然指向自己。
4. **说明文件**——生成 `THIRD-PARTY-NOTICES.md`（扫 `node_modules` 里每个 `package.json` 的 `license` 字段），
   并把 `tools/installer/readme.html` 的占位符（`{{VERSION}}` `{{DATE}}` `{{INSTALL_DIR}}` `{{INSTALLER_PATH}}`）替换成真值，
   同时写进 `dist-installer/README.html` 和载荷根目录。
5. **编译安装器**——调 `makensis` 编 `tools/installer/installer.nsi`，全量 lzma 压缩。
6. **打包 zip**——7-Zip 把载荷压成 `QQagent-<version>-win.zip`。
7. **自检**——核对 16 个关键文件是否就位、最长相对路径是否在安全预算内、Setup 是不是合法 PE。

## 三、安装器行为（`tools/installer/installer.nsi`）

- **per-user 安装**：`RequestExecutionLevel user`，默认目录 `%LOCALAPPDATA%\Programs\QQAgent`，**不需要管理员权限**。
  装到自己用户目录也意味着：对方公司电脑没给他装软件的权限，这个包照样能装。
- **路径长度护栏**：目录页拦掉空路径和超过 **150** 字符的路径（Windows 的 260 上限，减去载荷里最长相对路径 72 与余量）。
- **系统检查**：32 位系统直接拒绝；低于 Windows 10 给一次性警告，可以选择继续。
- **覆盖安装**：先 `taskkill` 掉正在跑的 `QQ Agent.exe`，再把 `data`、`snowluma/config`、`snowluma/logs`、
  `dsh-work` 临时挪到 `_qqagent_preserve`，铺完新文件再挪回来 → **升级不动配置与聊天记录**。
- **程序入口位置**：`QQ Agent.exe` 在 `node_modules\\electron\\dist\\` 里
  （Electron 的可执行文件必须和同目录的 `resources/`、`*.dll`、`*.pak` 待在一起，挪到根目录就起不来）。
  快捷方式、`DisplayIcon`、完成页的「立即运行」全部指向这个真实路径，参数固定为 `"$INSTDIR"`（Electron 官方约定：exe 后面那个参数就是 app 目录）。
  所以桌面上双击图标是正常的；如果自己手动找 exe，请按上面的路径找。
- **快捷方式**：桌面一个（带参数 `"$INSTDIR"`，和 Electron 官方约定一致），开始菜单一个文件夹（启动 / 使用说明 / 卸载）。
- **卸载**：默认**保留** `data`；卸载向导里有一页专门的复选框，勾了才连 `data` 一起删。
  静默卸载（`/S`）等价于「保留」——不会有人在没点确认的情况下丢数据；
  要在脚本里连数据一起清，必须显式写 `Uninstall.exe /S /PURGEDATA=1`
  （`un.onInit` 里用 `${GetParameters}` + `${GetOptions}` 读这个开关）。
- **注册表**：`HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\QQAgent`，
  含 DisplayName / DisplayVersion / Publisher / DisplayIcon / InstallLocation / UninstallString /
  QuietUninstallString / EstimatedSize / NoModify / NoRepair → 出现在「应用和功能」里，能正常卸载。

### 为什么程序目录必须可写

`src/app.js:678-682` 每次启动协议端前会重写 `snowluma/loadNapCat.js`（注入入口），
`src/dsh-task.js:9` 默认把任务工作区放在 `ROOT/dsh-work`。
所以安装目录**不能**选 `C:\Program Files`（普通用户不可写）。安装器默认值和文档都是 `%LOCALAPPDATA%`，
这是有意的；如果对方非要装到别处，要选自己有写权限的目录。

## 四、构建前置

| 依赖 | 用途 | 找不到时 |
| --- | --- | --- |
| Node.js ≥ 20 | 跑构建脚本 | 直接失败（工程本来就是 Node 项目） |
| `makensis` | 编译 NSIS 安装器 | 脚本会从 `npm` 取 `@nsis-u/makensis` 解到 `dsh-work/nsis/`，网络不通就失败 |
| `rcedit` | 写 exe 图标 / 版本资源 | 脚本会尝试从 `npm` 取；仍失败则**跳过品牌化**，照常出包 |
| 7-Zip | 打免安装 zip | 跳过 zip，Setup 照出 |
| 工程的 `data/config.json` | 便携包管线靠它算「哪些是密钥」 | 直接失败（`make-portable.mjs` 要求它存在） |

查找顺序可以用环境变量覆盖：`QQAGENT_MAKENSIS`、`QQAGENT_RCEDIT`、`QQAGENT_7Z`。

两个容易被自己坑到的构建细节：

- **`installer.nsi` 必须带 UTF-8 BOM**。makensis 3.03 只认「带 BOM 的 UTF-8」或 ANSI/UTF-16，
  不带 BOM 的中文脚本会当场报 `Bad text encoding: ...installer.nsi:2`。
  编辑器或 git 配置吃掉 BOM 是常事，所以 `compileInstaller()` 在调 makensis 前会检查并强制补回。
- **`EstimatedSize` 用 `${GetSize}` 的第一个输出**。这个宏对 `/S=0K` 的输出顺序是
  `$0`=KB 体积、`$1`=文件数、`$2`=文件夹数（和 NSIS 文档给人的印象不一致，读过
  `Include/FileFunc.nsh` 的 `GetSize_` 尾部才看得清）。写成 `$1` 会让「应用和功能」里
  显示 1657 KB 这种文件数当体积的鬼值。

### 常用参数

```bash
node tools/make-installer.mjs                 # 全流程
node tools/make-installer.mjs --skip-zip      # 不打 zip（省一半时间）
node tools/make-installer.mjs --stage-only    # 只做载荷，不编安装器（调图标/文案时用）
node tools/make-installer.mjs --reuse-app     # 复用上次载荷，只重编安装器 / 只重换 README
node tools/make-installer.mjs --out D:\tmp\dist   # 换输出目录
node tools/make-installer.mjs --version 1.2.0     # 覆盖版本号（默认读 package.json）
```

调安装器界面或 README 文案的正确姿势：

```bash
node tools/make-installer.mjs --stage-only   # 第一次把载荷铺出来
# 改 tools/installer/installer.nsi 或 tools/installer/readme.html
node tools/make-installer.mjs --reuse-app --skip-zip   # 一条命令重编，几十秒
```

## 五、体积与时间参考

| 项目 | 数值 |
| --- | --- |
| 载荷文件数 | 1657 个（装完后 1658 个，多出来的是 `Uninstall.exe`） |
| 载荷体积（磁盘） | 440 MB |
| Setup exe | **120 MB**（lzma 全压缩，实测 125,499,341 B） |
| 免安装 zip | **173 MiB**（实测 180,663,917 B；`-mx=5`，比 Setup 大是正常的） |
| 全新构建（含载荷） | 3～5 分钟，瓶颈是 lzma 压缩 |
| `--reuse-app` 重编 | 实测 **335～391 秒**（SingleCore 压缩 440 MB，随机器负载波动） |

载荷里最大的一块永远是 `node_modules/electron/dist`（Electron 本体约 245 MB），删不掉——
对方电脑上不需要装 Node，就是因为把这套运行时一起带过去了。

## 六、发出去之前必须自己验一遍

```bash
# 1) 静默装到临时目录，看文件数与卸载键
dist-installer\QQagent-Setup-1.0.0.exe /S /D=%LOCALAPPDATA%\Programs\QQAgentTest
dir "%LOCALAPPDATA%\Programs\QQAgentTest" /b | find /c /v ""
reg query HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\QQAgent

# 2) 启动，确认控制台能打开
"%LOCALAPPDATA%\Programs\QQAgentTest\node_modules\electron\dist\QQ Agent.exe" "%LOCALAPPDATA%\Programs\QQAgentTest"
curl http://127.0.0.1:3211/console/          # 应 200
curl http://127.0.0.1:3211/api/status        # 应 200 + JSON

# 3) 静默卸载，确认默认保留 data
"%LOCALAPPDATA%\Programs\QQAgentTest\Uninstall.exe" /S
dir "%LOCALAPPDATA%\Programs\QQAgentTest" /b          # 应只剩 data

# 4) 再装一遍，这次彻底删（连 data 一起）
"%LOCALAPPDATA%\Programs\QQAgentTest\Uninstall.exe" /S /PURGEDATA=1
dir "%LOCALAPPDATA%\Programs\QQAgentTest"             # 应「找不到文件」，目录整个消失
reg query HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\QQAgent   # 应「找不到」
```

> 卸载测试要用 `Start-Process -Wait` 或在命令行里等它跑完，别用 `&` 直接调用——
> `&` 拿到的是立即返回，此时安装树还在异步删除，采到的「残留 1～4 个文件 + 只剩 EstimatedSize」
> 是采样假象，不是卸载器 bug（`QQAgentTest` 三次 `/S /PURGEDATA=1` 复测均为目录消失、两个注册表键清空）。

验收清单：

- [ ] `makensis -V2` 零 warning 编过；
- [ ] 静默安装后文件数 = 1658（载荷 1657 + `Uninstall.exe`），含 `node_modules\electron\dist\QQ Agent.exe`、`README.html`、`THIRD-PARTY-NOTICES.md`；
- [ ] 桌面与开始菜单快捷方式指向 `QQ Agent.exe`，参数是安装目录；
- [ ] 注册表卸载键齐全，`EstimatedSize` ≈ 450000（KB，即 440 MB；不是文件数）；
- [ ] 启动后 `/console/` 与 `/api/status` 都 200；
- [ ] 卸载后 `data/` 还在，`Programs\QQAgent` 里只剩 `data`；
- [ ] `/S /PURGEDATA=1` 再卸一次，安装目录整个消失、`HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\QQAgent` 与 `HKCU\Software\QQAgent` 都被清掉；
- [ ] 载荷全树扫一遍，零 QQ 号 / 群号 / 密钥命中；
- [ ] `SHA256SUMS.txt` 与实际文件哈希一致。

## 七、签名与「未知发布者」

这个包**没有代码签名**（个人项目，EV 证书成本不划算）。后果是：

- 对方双击时 Windows SmartScreen 会弹「Windows 已保护你的电脑 / 未知发布者」；
- 点「更多信息」→「仍要运行」就能装，这不是病毒提示，是没有证书的必然结果。

`README.html` 第五节专门写了这段，还给了 `certutil -hashfile ... SHA256` 的核对方法，
让对方能自己确认拿到的文件和 `SHA256SUMS.txt` 对得上。

想彻底消掉这个提示，只有两条路：买代码签名证书（OV/EV，每年付费），或者
把这套东西提交给微软做 SmartScreen 信誉积累（要大量正常下载量）。两条都和代码无关，自行权衡。

## 八、发什么给对方

最小集：

```
QQagent-Setup-1.0.0.exe
README.html
SHA256SUMS.txt
```

对方拿到之后要做的只有三步（README.html 第一节）：

1. 双击 Setup，一路下一步（不需要管理员权限）；
2. 桌面图标启动 → 浏览器自动打开 `http://127.0.0.1:3210/console/` → 扫码登录协议端
   （**扫码前先退出电脑版 QQ**）；
3. 控制台里填群号 + 自己的 API Key → 点「一键启动」。

对方电脑上必须具备：Windows 10/11 x64、PC 版 QQ（NT 版）、一个**小号**、自己的模型 API Key。
这些 QQ Agent 没法代劳——协议端注入的是本机 QQ 客户端。

## 九、已知边界

- **协议端不在包里就等于没有**：载荷里 `snowluma/` 只带骨架，`NapCatWinBootMain.exe` / `napcat.mjs` 这些是必须的；
  本机构建时从工程里带过去的是完整的，但如果你换成纯净仓库构建，需要自己把 NapCat.Shell 解压进去。
  少了它们，程序会明确提示 `SnowLuma/NapCat 文件不完整，缺少：…`（`src/app.js:673`）。
- **注入 QQ 需要管理员权限**：普通权限启动时协议端注入会失败，`README.html` 排错表里写了「右键 → 以管理员身份运行」。
- **唱歌 / 语音增强环境不随包**：`rvc/`、`gpt-sovits*/`、`diffsinger*/` 在 `.gitignore` 里，体积几十 GB，
  要用的话单独打 `--with-ai` 的便携包，别混进安装包。
- **杀软误报**：Electron 程序 + 注入型协议端，启发式引擎偶尔报毒。文档里写了「别关 Defender，先核对哈希、再考虑加白名单」。
- **`.gitignore` 已忽略 `dist-installer/`**：产物不进仓库。
