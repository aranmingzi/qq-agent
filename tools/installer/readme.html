QQ Agent 使用说明

Windows 版 · 版本 {{VERSION}} · 构建于 {{DATE}} · MIT 协议开源
先看这三条，能省掉九成的麻烦：
1. 这个程序只是外壳，真正跟 QQ 通信的是「协议端」（NapCat）。协议端要靠注入已登录的 PC 版 QQ 工作。
2. 第一次用，请先开一个 QQ 小号 登录 PC 版 QQ，再启动本程序。别用主号试。
3. 程序自带协议端文件，但不带 QQ 本体，也不带你的 API Key：模型要你自己的 Key，QQ 要你自己登录。

一、第一次使用

  1. 双击桌面上的「QQ Agent」 装完之后桌面和开始菜单各有一个图标。首次启动会花十几秒初始化数据目录，之后会自动打开浏览器里的控制台。
  2. 在控制台里扫码登录协议端 控制台地址形如 http://127.0.0.1:3210/console/（端口可在设置里改）。点「启动 / 扫码」，用手机 QQ 扫那张二维码。
    扫码前请先退出电脑 QQ，否则注入会顶掉你正在用的登录态。
  3. 填群号与 API Key，点「一键启动」 API Key 是你自己的模型服务商发的；群号填要接管的那个群。填完点「一键启动」，日志区出现连接成功就可以在群里说话了。
两条红线：
· 协议端会注入你的 QQ 进程，属于非官方用法。用小号，别用主号，也别拿主号所在的群做实验。
· 不要把 data 文件夹发给别人——里面存着你的 API Key、群号配置和聊天记录。

二、提示「协议端未安装」怎么办

如果启动时提示找不到 NapCatWinBootMain.exe / napcat.mjs 之类，说明协议端文件没到位。两个办法，任选其一：

办法 A：重跑安装器

直接再运行一次 QQagent-Setup-{{VERSION}}.exe。它是覆盖安装，不会动你的 data 文件夹，协议端文件会被补齐。

办法 B：手动放文件

把 NapCat 的 shell 包整个解压到安装目录下的 snowluma 里，即：

{{INSTALL_DIR}}\snowluma\

放好后应能在该目录里看到 napcat.mjs、NapCatWinBootMain.exe、qqnt.json 这几个文件。

注意别拿错包：要的是 NapCat.Shell.zip（约 30–50 MB，含完整的 Node 运行时与注入器）， 不是那种几百 KB 的 OneKey 精简包——小包里没有 NapCatWinBootMain.exe，放进去也用不了。

三、更新与回滚

平时不用管版本。程序启动时会检查更新，发现新版本会在界面上提示，要你点两次确认才会开始下载：

  • 第一次确认：是否现在下载。
  • 第二次确认：下载完成，是否立刻重启并切换过去。

任何一步失败（网络断了、校验不通过、新版本起不来），都会自动回退到当前正在用的版本，不会把程序搞坏。 更新过程不碰 data 文件夹，配置、聊天记录、记忆都在原处。

想手工更新也一样：下载新的 QQagent-Setup-*.exe 直接覆盖安装即可。

四、卸载

入口有两处：设置 → 应用 → 已安装的应用 里找「QQ Agent」，或开始菜单文件夹里的「卸载 QQ Agent」。

卸载流程里会让你选一次：

  • 默认保留数据：程序文件、桌面图标、开始菜单项都删掉，但 data 文件夹留着。以后重装还能接着用，聊天记录和记忆都在。
  • 勾选「一并删除 data 文件夹」：连 API Key、群号配置、聊天记录、记忆、日记一起删，删了不可恢复。

静默卸载（命令行跑 Uninstall.exe /S）等同于「保留数据」。 真要连数据一起清，加一个显式开关：Uninstall.exe /S /PURGEDATA=1—— 不写这个参数就一律保留，免得脚本一跑就把聊天记录带走。

卸载不会动这两样：你装过的 PC 版 QQ 本体，以及程序自己注入时产生的 QQ 缓存。 这个安装包只删它自己装进去的文件。

另外，程序的配置与聊天记录全部在安装目录的 data 里（不散落在 %APPDATA%）， 所以只要 data 还在，重装就能原样接着用。

五、Windows 提示「未知发布者」

这个包没有买代码签名证书，所以你双击时 Windows 大概率会拦一下，SmartScreen 会显示「Windows 已保护你的电脑」或「未知发布者」。
未签名 ≠ 有毒，但也确实意味着系统没法替你验证来源——所以下面这一步请务必自己核对一遍。

核对哈希（30 秒）

压缩包里附带了 SHA256SUMS.txt。打开 PowerShell，执行：

certutil -hashfile "{{INSTALLER_PATH}}" SHA256

把输出的一长串字符跟 SHA256SUMS.txt 里对应那一行对比，完全一致才继续。

继续安装

SmartScreen 弹窗里点「更多信息」→「仍要运行」。这一步只在首次运行时出现。

关于签名

项目采用「SHA-256 清单 + 独立发布渠道比对」的方式做完整性校验，而不是商业代码签名证书。 如果你是从别人手里转存的安装包，请回到原始发布渠道核对哈希再运行。

七、常见问题

现象原因与处理
启动后浏览器没弹出来手动访问 http://127.0.0.1:3210/console/。如果连不上，看托盘是否已在运行、端口是否被占用（设置里能改端口）。
扫码后立刻掉线多半是电脑 QQ 还开着，注入被顶掉。退出 PC 版 QQ 后重来。
注入失败 / 提示权限协议端要往 QQ 进程里注入，需要管理员权限。右键程序 →「以管理员身份运行」。
提示找不到 QQ.exe本机没装 PC 版 QQ（QQNT 新版），或装在非常规路径。先装官方 QQ 并登录一次再试。
群里的机器人不回话依次检查：协议端是否在线、群号是否填对、API Key 是否有效（控制台有测试按钮）。
杀软报毒协议端注入行为容易被启发式规则命中。请把安装目录加入信任区；不要为此关闭 Defender 全局防护。
想换台电脑用重装安装包，然后把旧机器的 data 文件夹拷到新机器的安装目录下即可。
