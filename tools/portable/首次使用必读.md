# QQagent 使用说明

一个跑在你自己电脑上的 QQ 机器人：接住群消息和私聊，按人设接话，会记群梗、写日记、发语音、点歌；装了唱歌包还能用 AI 翻唱。

---

## 一、先看电脑够不够

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 / 11，64 位 |
| QQ | **PC 版 QQ（NT 架构）**，官网下最新版就行，必须先登录 |
| QQ 号 | 一个能登录的号，**建议用小号**（机器人会一直挂着） |
| 磁盘 | 核心版约 1GB；唱歌增强包再加 50GB |
| 显卡 | 只用对话：无要求。要唱歌：NVIDIA 显卡，6GB 显存以上更舒服 |

> 为什么必须要 PC 版 QQ：机器人不是模拟登录，而是把程序挂进本机 QQ 进程里（NapCat）。这一步绕不过去。

---

## 二、五步跑起来

**1. 解压到纯英文路径**
推荐 `C:\QQagent`。不要放桌面、下载文件夹、OneDrive 同步目录（中文路径和同步盘都可能让 Python 环境出怪问题）。

**2. 装好 PC 版 QQ，登录小号**，QQ 保持在前台或后台运行。

**3. 双击 `启动 QQagent.bat`**
- 会先弹一个黑窗口做自检，几秒后出现主界面，黑窗口可以关掉
- 如果之后连 QQ 一直失败，关掉程序，**右键 → 以管理员身份运行**（挂进 QQ 进程需要管理员权限）

**4. 控制台里填三样东西**（首次打开会自动跳到「设置」页）
- **模型**：填 API 地址 + API Key + 选模型。任何 OpenAI 兼容的服务都行（DeepSeek、通义、中转站…）
- **白名单**：点「选择群」，从你的 QQ 里直接勾选要它参与的群 / 好友
- 顶部有「体检卡」，哪一项红灯就补哪一项

**5. 验证**：「存档」页找到那个群，点「发测试消息」，群里收到就说明全通了。

> 白名单不设它谁都不理——这是防止它在你的群里乱说话的保护，不是 bug。

---

## 三、把它连上 QQ（自带 NapCat，不用另装）

1. 控制台左侧「SnowLuma」页 → 点「启动 QQ」
2. 出现二维码 → 手机 QQ 扫码登录
3. 显示在线后回「存档」页开始用

**扫码后一直显示离线？** 按顺序查：
- 是不是没用管理员权限运行（最常见）
- 本机 QQ 是不是 NT 架构新版
- 关掉程序重开一次再扫码（协议端只在登录那一刻读端口配置）

---

## 四、数据、备份、卸载

- 所有东西都在 `data/` 目录：`config.json`（设置）、`messages/`（聊天存档）、`memory/`（长期记忆）、`diary/`（日记）
- **备份** = 复制整个 `data/` 文件夹
- **换电脑** = 把整个 QQagent 文件夹拷过去，删掉 `data/electron/` 再启动
- **卸载** = 直接删整个文件夹。没有注册表残留、没有系统目录污染

---

## 五、手机当遥控器（可选）

电脑上打开 `http://127.0.0.1:3210/m/` → 「手机访问」卡片点开启 → 出现二维码 → 手机连同一个 WiFi 扫码。

手机端只能看状态、改常用设置、暂停/重启，不能扫码登录、不能看长聊天记录——这是故意的权限收敛。

---

## 六、唱歌包（只有拿到增强包才需要）

1. 把唱歌增强包解压并**覆盖到同一个 QQagent 目录**（会合并出 `rvc/`、`diffsinger-env/`、`gpt-sovits-app/` 等文件夹）
2. 再双击一次 `启动 QQagent.bat`，自检会自动把 Python 路径指到包内（这一步就是换电脑后唱歌为什么不坏的原因）
3. 第一次唱会比较慢（要分离人声、扒旋律），唱过的歌有缓存，第二次快很多

唱歌包里的"人声模型"决定音色。想换音色，把新的 `.pth` 放进对应模型目录，在控制台「语音/唱歌」里选。

## 七、常见问题

**黑窗口一闪就没了？**
压缩包没解压完整（缺 `node_modules`），整包重新解压。或按住 Shift 右键 → 在此处打开命令行，手动运行 bat 看报错。

**控制台打不开 / 白屏？**
端口被占用会自动往后找，看黑窗口里打印的地址；也可以直接试 `http://127.0.0.1:3211/console/`。

**它一句话都不说？**
按顺序查三件事：① 白名单有没有加这个群 ② 设置页点「测试一下」看 API 通不通 ③ 群里是不是需要 @ 或提到它（看「参与度」相关设置）

**会乱发消息吗？**
不会。白名单 + 发送限频 + 预算保险丝（设置里可配每日成本上限，超了自动暂停）。

**花钱吗？**
花的是你填的那个 API 的钱。机器人本身免费。

**能同时登两个号吗？**
一套程序一个 QQ。要两个就复制两份文件夹，分别登录。

## 八、给会看代码的人

- 默认端口 3210，被占用自动 +1；`127.0.0.1:3210/console/` 是新版控制台，`/legacy/` 是旧面板兜底
- 便携模式：包根存在 `portable.flag` 时，Electron 的 userData 落在 `data/electron/`，单实例锁不会和其他副本打架
- `diffsinger-env` 是 Python venv，`pyvenv.cfg` 记录的是创建机器的基础 Python 绝对路径。首次启动由 `tools/portable-setup.mjs` 改写为包内 `runtime/py312`
- 自检不依赖系统 Node，用的是 `ELECTRON_RUN_AS_NODE=1 electron.exe tools/portable-setup.mjs`
- 源码可改：`src/*.js`（后端）、`console/`（React 控制台，改完需 `npm --prefix console run build:electron`）、`ui-mobile/index.html`（手机版，改完即生效）
